# CLASS ONE – Stationery Management System

### A Modern Website for Class One Stationery

## 📌 About the Project

**Class One** is a stationery business website designed to showcase stationery products and services while providing a platform for managing business operations.

The project aims to improve how the business presents its products, interacts with customers, and manages daily activities such as sales and expenses.

The website features a modern, user-friendly interface with a clean design and easy navigation.

## 🚀 Features

### 1. Website Sections
- **Home:** Introduction to Class One Stationery.
- **About:** Information about the business.
- **Products:** Displays available stationery products.
- **Services:** Showcases the services offered.
- **Gallery:** Displays business-related images.
- **Contact:** Allows customers to get in touch.

### 2. User Authentication
- User registration.
- Secure login.
- User dashboard.
- Logout functionality.
- Firebase Authentication integration.

### 3. Sales Management
- Record customer sales.
- Enter product quantities.
- Calculate sales totals.
- Store sales records.
- View and manage recorded sales.

### 4. Expense Management
- Record business expenses.
- Store expense information.
- Track business expenditure.

### 5. Shopping Cart
- Add products to the cart.
- Manage selected products.
- Calculate cart totals.
- Store cart information using Local Storage.

## 🔥 Firebase Integration

Class One uses Firebase services to support its business management functionality.

**Firebase services include:**
- Firebase Authentication for account registration and login.
- Cloud Firestore for storing sales and expense records.

## 💻 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure that the Firebase configuration is correctly set up.
4. Install the Live Server extension if you haven't already.
5. Right-click `index.html`.
6. Select **Open with Live Server**.

The website will open in your default browser.
